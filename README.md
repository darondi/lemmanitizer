# Морфологический анализатор для русского языка
## Задание

Лемматизировать текст и приписать леммам частеречные теги.
Программа выполняет:
- лемматизацию (приведение слова к словарной форме)
- определение части речи

Вывод в формате:
токен{лемма=тег}

## Данные

- корпус UD Russian SynTagRus
- обучение на соответствующих файлах: ru_syntagrus-ud-train-a/b/c.conllu
- тестирование на файле: ru_syntagrus-ud-test.conllu

## Запуск

### Основной запуск

```bash
python main.py
```

### Оценка качества модели

```bash
python accuracy.py
```
или 
```bash
python main.py -t
```

## Пример использования

1. Запуск: 
```bash
python main.py
```

2. Ввод текста:
```
Введите текст:
Как только жизни ставишь крестик, она ставит нолик. Но если она ресторан, я занял лучший столик!
```

3. Получение результата:
```
Результат:
Как{как=CONJ} только{только=ADV} жизни{жизнь=S} ставишь{ставить=V} крестик{крестик=S} она{она=NI} ставит{ставить=V} нолик{нолик=S} Но{но=CONJ} если{если=CONJ} она{она=NI} ресторан{ресторан=S} я{я=NI} занял{занять=V} лучший{лучший=A} столик{столик=S}
```

4. Завершение по Ctrl + C
